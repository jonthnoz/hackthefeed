Findings and recommendations
1. Missing study returns 400 with the internal ENOENT path, whereas missing job returns 404. Reproduced GET /api/studies/missing-study. server/index.ts catches every error as 400. Return a friendly 404 for absent studies, retain 400 for input errors, and distinguish internal failures from input failures. Low demo impact; broken or stale study links get an inaccurate response.
2. All four retained references in the actual live smoke study have format equal to an empty string. analysisSchema permits empty format and research.ts stores it unchanged. Workspace renders an empty format label and SourceDrawer falls back to Format unavailable. Require meaningful format text at the analysis boundary or preserve the adapter fallback when qualification.format is blank. This is a real live-output completeness gap, not a provenance failure.
3. WPS curated evidence frames are ordered 0, 48.8, 34.2, 70.23 seconds. All four timestamps and OCR are genuine source evidence, but the frame strip goes backward after the flashcard proof. Recommend chronological ordering or explicitly labeling the 48.8-second frame as a prioritized evidence frame. Do not change timestamps to make the sequence appear chronological.
